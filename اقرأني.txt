خمن الكلمة — ملف المشروع الجاهز للآيفون والأندرويد
================================================

اقرأ أولاً الملف:

    خطوات-البناء.md

فيه كل خطوات البناء بالتفصيل: Xcode، التوقيع، المحاكي، الأرشفة،
متجر أبل، Android Studio، ملف المفتاح، ومتجر غوغل.


افتح المشروع
------------
آيفون / متجر أبل
  الملف:     ios/App/App.xcodeproj
  البرنامج:  Xcode على الماك
  ثم:        Signing → Team → ▶ للتجربة → Archive → رفع للمتجر

أندرويد / متجر غوغل
  المجلد:    android
  البرنامج:  Android Studio
  ثم:        Run للتجربة → Generate Signed Bundle → ارفع ملف aab

تعديل الكود ثم إعادة البناء
  من Terminal داخل هذا المجلد:
      npm install
      npm run native:sync
  ثم أرشف من Xcode / أعد بناء الأندرويد.
  التفاصيل في خطوات-البناء.md القسم 9.
