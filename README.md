# خمن الكلمة

لعبة تخمين كلمة عربية فصحى من خمسة أحرف. جاهزة للفتح في Xcode وAndroid Studio ولرفعها على المتاجر.

**الاسم:** خمن الكلمة  
**الحزمة:** `app.khamsa.game`  
**الإصدار:** 1.0.0

## ابدأ من هنا

الدليل الكامل بالعربي، خطوة بخطوة:

**[خطوات-البناء.md](خطوات-البناء.md)**

فيه: تجهيز الماك، فتح Xcode، التوقيع، التشغيل على المحاكي والآيفون، الأرشفة، App Store Connect، Android Studio، ملف التوقيع، Google Play، وإصلاح الأخطاء الشائعة.

## ماذا في المجلد

| المجلد | افتحه بـ |
|---|---|
| `ios/App/App.xcodeproj` | **Xcode** — آيفون ومتجر أبل |
| `android/` | **Android Studio** — أندرويد ومتجر غوغل |
| المجلد كامل | VS Code / أي محرر — لتعديل الكود |

نصوص صفحة المتجر: [`native/XCODE.md`](native/XCODE.md)

## أوضاع اللعب

- **كلمة اليوم** — لغز واحد يتجدد كل يوم
- **المراحل** — مراحل متتالية تُفتح واحدة بعد الأخرى

خمس خانات · ست محاولات · ه و ة حرفان مختلفان · ى و ي حرفان مختلفان · ا/أ/إ/آ حرف واحد.

إعلانات المكافأة اختيارية فقط (كشف حرف / فرصة إضافية).

تفاصيل AdMob: [`native/ADS.md`](native/ADS.md)
